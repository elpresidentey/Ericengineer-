## 🚀 Quick Deploy (5 Minutes)

### Option 1: Deploy to Vercel (Easiest)

1. **Push to GitHub**
   ```bash
   cd eric-electrical-tech
   git init
   git add .
   git commit -m "Eric Ohiol Engineering website"
   ```

2. **Create GitHub Repo** (if using GitHub CLI)
   ```bash
   gh repo create eric-electrical-tech --public --source=. --push
   ```

3. **Deploy on Vercel**
   - Go to [vercel.com](https://vercel.com)
   - Click "New Project"
   - Import your GitHub repo
   - Click "Deploy"
   - Done! Your site is live! 🎉

### Option 2: Test Locally

> **Note:** Windows has a compatibility issue with Next.js 16.2.7 build. The site will work perfectly when deployed to Vercel.

To test locally (if needed):
```bash
npm install
npm run dev
```
Visit `http://localhost:3000`

## 🗄️ Database Setup (Optional)

To enable dynamic content management:

1. **Create Supabase Account** → [supabase.com](https://supabase.com)
2. **Create New Project**
3. **Run SQL Scripts** → See `SUPABASE_SETUP.md`
4. **Add Environment Variables** in Vercel:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
5. **Redeploy**
