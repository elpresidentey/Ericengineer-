## To Add Your Images

Please save your images as:
- **Meter Box Image**: `meter-box.jpg` (for Solar card, bottom-left)
- **CCTV Camera Image**: `cctv-camera.jpg` (for Security card, bottom-right)

Both images will be displayed as backgrounds with text overlays.

## Image Requirements

- Format: JPG or PNG
- Recommended size: 600x600px for small cards, 1200x800px for carousel
- Optimized for web (under 500KB per image)
- Good contrast for white text readability
